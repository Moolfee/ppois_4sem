# LAB_3 - Moorhuhn

Учебная 2D-игра на `pygame` в духе `Moorhuhn / Crazy Chicken`.

## Возможности

- главное меню;
- экран настроек;
- справка;
- таблица рекордов;
- игровой раунд на время;
- ручная перезарядка;
- три глубины обычных целей;
- отдельная вылазящая курица;
- многослойный параллакс из одного общего background sheet;
- внешние JSON-конфиги;
- музыка и звуки из папки `assets/audio`;
- fallback-эффекты, если некоторых файлов нет.
- автотесты только для исходного кода `src/`.

## Запуск

```bash
cd LAB_3
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e .
python3 -m moorhuhn
```

Альтернативно:

```bash
python3 src/main.py
```

## Тесты

```bash
cd LAB_3
source .venv/bin/activate
python3 -m pytest tests
```

Если зависимости для тестов ещё не установлены:

```bash
python3 -m pip install -e .[dev]
```

## Управление

- `ЛКМ` — выстрел
- `R` или `ПКМ` — перезарядка
- `Esc` — пауза / продолжение
- `Стрелки вверх/вниз` — навигация по меню
- `Enter` — подтверждение в меню и на экранах результатов

В паузе используются экранные кнопки.

## Правила

- Раунд длится ограниченное время.
- Очки начисляются за попадания по движущимся целям.
- Чем дальше цель, тем она меньше и тем больше стоит.
- Магазин ограничен семью патронами.
- Перезарядка выполняется вручную.
- После конца раунда результат можно сохранить в таблицу рекордов.

## Структура

- `config/game_config.json` — окно, камера, эффекты, UI-тема, аудио, фон, лидерборд
- `config/enemies.json` — обычные птицы и вылазящая курица
- `config/assets_manifest.json` — описание sprite sheet и UI-ассетов
- `data/highscores.json` — таблица рекордов
- `data/settings.json` — пользовательские настройки
- `assets/background/` — фон и экран загрузки
- `assets/targets/` — спрайт-листы целей
- `assets/ui/` — прицел, патроны, след от промаха
- `assets/audio/` — музыка и звуки
- `src/moorhuhn/app/application.py` — инициализация приложения и главный цикл
- `src/moorhuhn/game/world.py` — игровая логика, параллакс, цели, HUD
- `src/moorhuhn/media/assets.py` — загрузка графических ассетов
- `src/moorhuhn/media/audio.py` — загрузка музыки и звуков
- `src/moorhuhn/ui/screens.py` — все экраны и экранный менеджер

## Конфиги

В `config/game_config.json` настраиваются:

- окно;
- таймер раунда и камера;
- визуальные игровые эффекты и lifetime следов от промахов;
- оружие;
- громкость по категориям;
- UI-палитра, прозрачности, HUD и пауза;
- слои параллакса;
- ширина игрового поля и скорость панорамирования камеры.

В `config/enemies.json` настраиваются:

- параметры обычных целей по глубинам;
- очки, интервалы спавна и диапазоны высот;
- параметры вылазящей курицы.

В `config/assets_manifest.json` настраиваются:

- sheet обычных куриц;
- sheet вылазящей курицы и её смерти;
- прицел;
- патроны;
- след от промаха.

## Замечания

- Музыка меню читается из `assets/audio/music_menu/`.
- Музыка раунда читается из `assets/audio/music_gameplay/`.
- Эффекты читаются из `assets/audio/sfx_ui/`, `assets/audio/sfx_weapon/` и `assets/audio/sfx_gameplay/`.
- Если часть звуков отсутствует, игра использует короткие встроенные fallback-эффекты.
- Для проблемных `mp3` создаётся технический кэш в `data/audio_cache/`.
